# livecontainer-source

LiveContainer 自用自动更新源。每天 11:00（北京时间）自动检查上游新版本并更新 `apps.json`。

## 添加到 LiveContainer

来源 → `+` → 粘贴：

```
https://raw.githubusercontent.com/ZEERDEER/livecontainer-source/main/apps.json
```
